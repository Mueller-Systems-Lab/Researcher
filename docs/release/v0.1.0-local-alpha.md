# Release Notes — v0.1.0-local-alpha

**Date:** 2026-05-20  
**Status:** Local Research Alpha  

---

## Summary

First validated local research pipeline with end-to-end quality gates. The system can execute a complete research cycle (Query → Search → LLM Summary → Report) using only local services (Ollama, SearXNG, Tor). All code quality gates are blocking and green.

---

## What Works

- ✅ **Quality Gate** (`make quality`): lint, typecheck, security, tests, coverage — all 6 blocking
- ✅ **Runtime Smoke** (`make runtime-smoke`): Ollama, SearXNG, Tor, Cloud check
- ✅ **Research Pipeline**: Query → SearXNG → Ollama → Markdown Report
- ✅ **Report Evaluation**: 4 scores (Source Coverage, Traceability, Hallucination Risk, Local-First), Overall: **99/100**
- ✅ **Multi-Query Evaluation**: 3+ queries with aggregate scoring
- ✅ **Regression Guard**: baseline thresholds with `--fail-on-regression`
- ✅ **Fresh Clone Onboarding**: clone → venv → `make quality` in <5 minutes
- ✅ **No Cloud Required**: all quality gates run without external services

## Upgrade/Setup Notes

```bash
git clone https://github.com/xxammaxx/Researcher.git
cd Researcher
git submodule update --init --recursive
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make quality
```
