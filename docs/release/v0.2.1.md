# Release Notes — v0.2.1

**Date:** 2026-05-28
**Status:** Local Research Alpha
**Previous:** [v0.2.0](v0.2.0.md)

---

## Summary

Third validated release. Focus on **Qwen3.5 Solo**, **Scraper Resilience**, and **Code Cleanup**. Gemma 4 has been fully removed — Qwen3.5-Uncensored-HauhauCS is now the sole primary model.

---

## What's New Since v0.2.0

### Qwen3.5-Uncensored-HauhauCS: Alleiniges Primary-Modell
- Gemma 4 komplett entfernt (#120): Alle Referenzen, Configs, Tests und Scripts bereinigt
- Qwen3.5 (@ Port 8082, 45 tok/s) jetzt das einzige Chat-/Summary-Modell
- ADR-017 formalisiert Qwen3.5 als Co-Primary → jetzt alleiniges Primary
- Prompt-Optimierung: enable_thinking-Konsistenz, Temperature-Sweep (#119)
- Best-of-3 Extraction mit proven params (temp 0.3, repeat_penalty 1.2)
- Research-Happy-Path scrapt echte Artikel (nicht nur Snippets)

### Scraper Resilience
- **scrapers/http_session.py** — Zentrales HTTP-Session-Management
  - Retry-Adapter mit exponentiellem Backoff (502, 503, 504, 505)
  - Zentraler User-Agent (Firefox 128 ESR Linux)
  - SSL-Fallback-Helper, JS-Detection, 505-Spezialbehandlung
- Scraper-Hardening dokumentiert (#118)

### Viewport-Matrix
- Tablet (768×1024) und Mobile (375×812) Tests aktiviert (#42)
- Screenshot-Baselines für alle Viewports

### Code Cleanup
- 5 dead-code lint errors in `research_happy_path.py` behoben (Gemma-Reste)
- Security B108: hardcoded `/tmp/` → `tempfile.gettempdir()`
- `qwen3.5_optimize.py`: Duplicate Gemma 4 Output entfernt
- `_build_summary_prompt()` Return-Type auf `dict` korrigiert
